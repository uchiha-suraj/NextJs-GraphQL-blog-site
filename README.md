## Key Features

- 🟢 Full content management from the Graph CMS panel — posts, categories, comments
- 🟢 Every feature and piece of content is controllable from the CMS, no redeploys needed
- 🟢 Next.js + GraphQL data layer for fast, efficient content fetching
- 🟢 Optimized for performance — one of the fastest builds in this portfolio
- 🟢 Fully server-side rendered for strong SEO and quick first paint

## Tech Stack

| Technology | Purpose |
|---|---|
| **Next.js** | React framework — handles routing and server-side rendering |
| **GraphQL** | Data querying and manipulation for the content API |
| **GraphCMS** | Headless CMS for backend content management |
| **Tailwind CSS** | Utility-first UI styling |
